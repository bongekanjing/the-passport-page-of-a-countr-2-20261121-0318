# The Passport Page of a Country That Isn't There

An invented passport spread for the **Republic of Solmara**, drawn entirely
in code. `main.py` (pure Python stdlib, no third-party libraries) renders a
1024x1024 PNG of the open spread and writes it to `/output/entry.png`.

The spread shows Mara Elena Velis of Porto Lume: a data page with a drawn
portrait, coat of arms, and a machine-readable zone with real ICAO check
digits; and a visas page with a Talmeria multiple-entry visa (condition:
holder may not take paid employment), five arrival/departure stamps from the
neighbouring countries Nordvell, Talmeria and Ostkovia — every stamp dated
after the passport's 12 Mar 2024 issue — plus an island chart of Solmara
and the observations line.

## Run

```sh
python3 main.py   # writes /output/entry.png, deterministic
```
